ANTI COLLISION SHIP — GITHUB PAGES UPLOAD
Team: 11th Science, MEASI

Upload BOTH index.html and prototype.jpg to the ROOT of your public GitHub repository.
Do not upload this ZIP as the website; extract it first.

Then open repository Settings > Pages.
Under Build and deployment choose Deploy from a branch.
Choose branch main and folder /(root), then Save.
Your website will appear at https://YOUR-USERNAME.github.io/anti-collision-ship/

The physical model is an educational prototype, not a certified shipboard system.
